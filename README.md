## 🛰️ Sindh Forest Degradation & LST Trend Analysis

<a href="https://github.com/abdurafay19/sindh-vegetation-lst-analysis">
  <img src="https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github" alt="View Repository">
</a>

A geospatial study investigating vegetation degradation, land-cover change, land surface temperature, and infrastructure pressure across **Sindh, Pakistan**, using approximately **24 years of Earth observation data (2001–2024)**.

The project combines:

- NDVI Sen's Slope
- Land Surface Temperature trends
- NDVI–LST correlation
- Land-cover transitions
- Road-distance analysis
- District-level vulnerability analysis

**Focus:** `Remote Sensing` · `GIS` · `Google Earth Engine` · `Python` · `Spatial Data Science`
